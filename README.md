# 💫 About Me:
🔭 I am a **Flutter Developer** and **ASP.NET Core Backend Developer** passionate about clean architecture, scalable systems, and building high-quality applications. I love working with modern technologies—whether in the world of Flutter, Riverpod, and clean UI patterns, or in the backend with ASP.NET Core, CQRS, MediatR, and WebSockets/SignalR.

🔥 My experience includes building **real-time systems**, implementing **Onion Architecture**, designing **CQRS-based applications**, working with **PostgreSQL**, and creating robust and maintainable mobile apps using **Riverpod**, **Bloc**, **Freezed**, **Drift**, **Dio**, and more.

👨‍🏫 I enjoy sharing knowledge, exploring new technologies, and continuously improving my craft.

🤝 I’m open to collaborating on serious, long-term projects. Feel free to reach out if you’d like to work together!
